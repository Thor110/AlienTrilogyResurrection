Fixes moved from ALTViewer's model export into the file (Claude, 2026)

ALTViewer's OBJ export used to correct crate faces (the same faces as L111LEV) by giving them other UVs, so the fix never reached
the game. Each one is now a byte change that gives the same result in the level file itself. Same faces, same offsets and same fix as L111LEV.

A turn rotates the face's four vertex indices (16 bytes at the face's offset), keeping its winding. A mirror
sets the flag byte (offset + 0x12) to its mirrored partner. A texture change sets the texture index
(offset + 0x10, two bytes) to the one the export borrowed. The old export remap is listed so the mapping
stays on record: "face N's UVs as a,b,c,d" means corner k took corner p[k] of face N's UVs.
